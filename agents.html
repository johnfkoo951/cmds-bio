에이전트와 하네스

연구와 일을 운영하는
에이전트 시스템

구요한이 매일 쓰는 에이전트 시스템의 구조와 규모, 대표작입니다. 원문은 Zotero에서 시작하고, 에이전트는 하네스 위에서 일하며, 바꾸는 일은 사람이 승인한 뒤에만 합니다.

1. 원문은 Zotero에서 시작합니다

논문 서지, PDF, 하이라이트는 Zotero 한 곳에 둡니다. 볼트와 위키는 서지를 복사하지 않고 인용 키로 원문을 가리킵니다. 에이전트도 Zotero를 읽기만 합니다.

  1. 01
    Zotero

    서지, PDF, 하이라이트의 원본

  2. 02
    인용 키

    Better BibTeX가 논문마다 바뀌지 않는 키를 붙입니다

  3. 03
    CMDS Zotero 플러그인

    인용 넣기, 주석 가져오기, PDF 해당 쪽 열기. 직접 만들어 공개했습니다

  4. 04
    볼트와 위키

    본문에는 인용 키만 두고, 에이전트는 키로 원문 위치를 확인합니다

3. 구조

아래 층일수록 오래 바뀌지 않습니다. 에이전트라고 부르는 것은 가운데 두 층뿐입니다.

하네스Claude Code, Codex

반복 실행, 도구, 맥락, 권한을 주는 실행 환경입니다. 맥 두 대에 OpenRig 작업 리그 8종을 나눠 둡니다(리서치, 블라인드 판정, 덱 제작, 구현과 리뷰 등).

지휘 에이전트9요한

일을 나누고 합치며, 밖으로 나가는 결과는 사람의 확인을 거칩니다.

전문 에이전트9개

연구, 글쓰기, 교육, 창작, 분석, 관계, 개발, 커뮤니티, 자문. 각자 자기 맥락에서 일하고 결과만 돌려줍니다.

스킬120여 개

에이전트가 필요할 때 꺼내 읽는 절차서입니다. 덱 제작, 논문 반입, 질문 수신함 처리 등. 스킬은 에이전트가 아닙니다.

규칙 파일CLAUDE.md, AGENTS.md 외

모든 에이전트가 먼저 읽는 공개 규칙입니다. 하네스가 바뀌어도 그대로 남습니다.

5. 지키는 원칙

  • 읽기는 맡기고, 쓰기는 승인 뒤에만 허락합니다.
  • 만든 에이전트와 검증하는 에이전트를 나눕니다.
  • 원문은 고치지 않고, 무엇을 왜 바꿨는지 기록을 남깁니다.
  • 에이전트를 만들기 전에 반복되는 절차부터 스킬로 적습니다.
